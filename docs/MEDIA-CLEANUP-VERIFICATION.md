# 双目录图片清理验证

日期：2026-11-14。工作目录 E:/codex/image2-canvas-work/mainline-merge，master。

## 实现范围

同一个「清理未使用图片」按钮覆盖 generated 与 assets；保留所有已保存项目的引用与编辑记录。无引用受管图片在写入十分钟后可清理，删除前必须预览并确认。不能把当前不显示的图层、对比原图或恢复备份视作垃圾。

服务端预览令牌五分钟内有效且只能消费一次。确认仅删除预览时的候选，文件签名/引用/任务状态变化即跳过；路径白名单、非递归扫描、lstat 排除符号链接。保留新写入文件和已成功尚未回填的任务结果。旧客户端路由返回 409，不会使用不完整引用清理 assets。

## 使用边界

当前浏览器全部项目是引用来源，不覆盖其他浏览器、其他电脑或仅导出的 JSON。清理前保存并关闭其他编辑窗口，相关外部项目先导入或备份素材。无法在没有这些项目数据的情况下保证它们引用的文件保留。清理结果不进入回收站，不能撤销。服务器重启加载新代码后，用户页面须刷新。
