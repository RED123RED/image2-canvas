# 单层再次拆分验证（2026-11-12）

## 使用方式

1. 打开分层作品，在右侧选中尚需细分的图片层（背景锁定时也可选择）。
2. 点击“再次拆分”，输入要分开的元素，选择套餐 Pro 或 Flash，再开始。每次开始消耗套餐额度。
3. 左侧看原层，右侧可切换“全部组合”或单个候选层；满意后“应用结果”，不满意则放弃。
4. 结果进入原位置的图层组，可折叠、整组移动或展开后独立编辑，子层可继续再次拆分。
5. 组内有隐藏原层备份，选组点“恢复拆分前图层”可恢复；此操作可撤销。
6. 点击“保存到画布”更新原节点的合成图；PSD 保留分组和隐藏备份，JPG/PNG 为合成图片。

## 当前边界

- 这是对选中图片层的 AI 再次拆分，不是手工套索抠图、矢量曲线或文字OCR；组内文字仍为位图。
- 一个节点同时保留一个待完成/待应用的再次拆分任务；关闭/刷新后点“查看再次拆分”检查原任务。放弃记录不取消远端调用、不退款。
- 选中层在任务期间被修改时，拒绝直接套用旧候选；可撤销改动恢复匹配，或放弃候选。提交结果不明时不自动重新收费。
- 最多64个活动图片层、12级嵌套。组支持移动、显隐、锁定、折叠、不透明度与同级排序；暂不支持跨组拖入/拖出或整组旋转缩放。
- 项目 JSON 含图层结构，但本地素材仍按已有机制引用；迁移机器须连同 assets/generated 保存。PSD/JPG为独立文件。
- 服务器路由、模型配置和其他节点处理逻辑未修改；新增分组渲染、引用收集与保存逻辑均围绕分层作品。
