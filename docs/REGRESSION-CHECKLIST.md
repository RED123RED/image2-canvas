# 发布前回归清单

执行 npm run verify 后，在桌面版中确认以下项目：

1. 新建、打开、复制、删除项目后，首页缩略图和节点数量正确。
2. 工作流中拖动单个节点、多选节点、分组画板和图片节点时保持流畅。
3. 生成中可以继续移动、缩放和连接节点；完成后结果图和下载功能正常。
4. 上传 PNG、JPG、WebP 后，画布显示预览，生图、裁剪、预览和下载使用正确图片。
5. 提示词、构图控制、模型回答与参考图端口只连接同类型接口；提示词节点的快捷镜头默认收起，点击标题栏眼睛按钮后才显示。在提示词节点中分别选择不同文字片段，再修改为红色、白色或字号，格式只作用于当前选区，嵌套样式后也不会串到其他文字；从外部或模型回答节点复制带颜色文本黏贴后，内容保持纯文本、换行保留且新内容统一为白色，即使光标位于已有样式的文字内部，`Ctrl+V` 也不能被画布节点粘贴逻辑拦截。刷新项目后样式仍保留，生成请求中的提示词纯文本内容不变。
6. 剧本流中的角色、故事卡、情绪曲线、分组、角色管理和对话脚本可以保存、复制、删除及撤销。
7. 关闭后重新打开项目，画布位置、节点、连线、对话和生成结果仍可恢复。
8. 成片预览节点上传或拖入本地视频后，连接 H3“参考视频”应把实际 `/api/video-assets/` 路径写入生成请求；不得因循环保护误判为空来源。
9. K2 白玉生成任务进入排队或运行状态后，节点按钮应显示“停止 K2 白玉”且可点击；取消后远端任务停止、生成中占位图移除，既有结果和提示词保持不变。
10. 新建 Image2 节点默认使用 GPT Image 2.5 Sunburst；可切换到 GPT Image 2.5、Flare、Sunburst 和 GPT Image 2，模型名称不显示冗余产品前缀。2.5 节点保留原 Image2 的五档比例，并显示 `1K`、`2K`、`4K` 输出档位与各自实际尺寸；新旧节点默认均为 `2K`。1K 的 `3:4` 必须显示并提交 `912 × 1216`，`9:16` 必须显示并提交 `864 × 1536`；其中 `9:16` 的 `4K` 必须显示并提交 `2160 × 3840`，`16:9` 的 `4K` 必须显示并提交 `3840 × 2160`。Flare 与 Sunburst 显示 `auto` 至 `max` 品质，基础 GPT Image 2.5 和旧 GPT Image 2 仅显示低、中、高品质。Image2 生成和参考图编辑请求必须显式使用 `output_format: "png"`，结果卡片的像素与下载扩展名必须来自图片实际字节，不能依赖网关的错误 MIME 标头。浏览器代码更新而本机服务未重启时，2.5 生成必须显示重启提示且不创建任务。
11. 模型回答节点可在 GPT-5.6、GPT-6 Astra、DeepSeek V4.1 Flash/Pro、Claude Sonnet 4.6、Claude Opus 5.5、Kimi K3 · 魔芋 AI 和 Kimi K3 · Moonshot 官方之间切换；旧项目中的 GPT-5.5 值必须兼容映射为 GPT-5.6。Claude 模型选择必须按节点值提交到 Claude 网关，默认仍为 Sonnet 4.6。两个 Kimi K3 选项实际提交的 API 模型均为 `kimi-k3`，但必须分别读取对应 key、请求对应网关，健康检查和回答请求必须使用同一网关，参考图仍按 OpenAI 视觉消息提交。提示词 Skill 可切换普通模型问答、MiniMax H3、南鸢图片反推、极简产品广告和品牌宣传短片。后两个选项必须各自显示独立的 H3 模式（自动识别、T2VA、I2VA、L2VA、FL2VA、Ref2VA）与 `3` 至 `15` 秒逐秒时长选择及对应说明与运行按钮文案；产品广告默认 `10` 秒，品牌宣传默认 `15` 秒，改变其中一个不能修改 H3 或另一个广告 Skill 的模式和时长。自动识别须按连接参考图数量选择 H3 的文生、首帧、首尾帧或多参考结构；手动模式必须原样提交并覆盖自动选择，单张图选择 `Ref2VA` 时输出多参考 H3 结构但不得虚构或新增参考图。服务端须将时长写入对应英文 H3 提示词，并且只返回可直接用于 H3 的英文提示词；输出不得声称已生成、验证或剪辑媒体，也不得杜撰产品或品牌事实。
