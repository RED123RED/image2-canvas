# 参考图局部修改验证

日期：2026-11-13；工作目录 E:/codex/image2-canvas-work/mainline-merge，master，基线 5a89c81。

## 使用

1. 点参考图右上角画笔按钮，点选多处、框选或圈选并填写每处要求。可用画笔、箭头和文字工具画示意；移动工具移动标记或在空白处拖动画面。
2. 默认火山套餐 Seedream 5.0 Pro，可选 Flash。生成修改预览后，关闭/刷新可恢复同一任务，不自动重发。
3. 拖动中轴对比；滚轮缩放，两图共用位置。点击「确认应用」直接更新当前节点，不新增参考图；再次打开仍可对比。
4. 严格保留其他部分时，框/圈选后开启保护选区外画面。物体、阴影、过渡都要包括在选区内；这是本地合成，不是模型保证只改选区。
5. 分层作品同样在原节点确认，已保存图层和未保存草稿独立保留为可恢复备份，活动图层显示修改结果。原有再次拆层、PSD/JPG/PNG 导出继续用原工具。

## 确认应用更新（2026-11-13）

按用户要求移除另存节点与另存原始图按钮，统一为确认应用。像素尺寸按原图核验，节点和下载都使用完整结果，解决旧预览最长边 720px、JPEG 质量 .82 在节点放大时的模糊；比较窗口 100% 缩放使用原生分辨率。这里保证保存/显示链路不额外降采样，并不承诺模型生成细节与原图相同。

兼容之前已另存的记录，可将已有预览应用回原节点，不重发请求。普通与分层图均保留原节点 ID/位置/连线，确认后刷新仍能对比。原分层数据采用既有可恢复组机制备份，未保存草稿单独保存；导出显示修改后的完整结果，PSD 同时保留原图层隐藏备份。

本轮未调用真实生图 API：使用独立测试项目及模拟返回验证。同节点确认专项 20 项、普通节点 21 项、分层异常 11 项；新增 3 项单元测试包括 64 层作品和旧版另存状态迁移。报告与测试导出在 output/local-edit-confirm-test，截图 output/playwright/local-edit-confirm-applied.png。
