# 分层编辑验证记录 · 2026-11-12

## 范围和实际操作

基于 master 的 821104c，新能力从参考图标题栏进入。普通生图/模型回答/视频路由不增加模式。原图保留，拆层结果集中到一个 image 节点，保存后继续输出普通合成图给下游。

1. 点击参考图“分层编辑”，选择火山套餐 Pro/Flash，可选填拆分要求，开始拆层。
2. 结果节点“编辑图层”打开独立编辑器。列表上方的图层显示在前；背景默认锁定。
3. 拖动图层移动；右下角手柄缩放；上方圆点旋转；也可输入精确位置、宽高、角度和不透明度。Shift 多选，方向键微调，Shift+方向键移动 10 像素。
4. 支持排序、隐藏、锁定、复制、删除、添加与替换图片；多选左对齐/居中/顶对齐。恢复初始布局可撤销。当前编辑草稿随项目保存，保存到画布才更新下游合成图。
5. PSD 导出独立位图层；JPG/PNG 导出合成。JPG 可指定背景色和质量，二者可调整宽度。PSD 保持文档原始画幅。

## 复跑方式

本地运行 npm start 后，使用独立 playwright-cli session 打开 http://127.0.0.1:45173，窗口至少 1600 × 1000。通过 run-code --filename tests/layer-editor.browser.js 和 tests/layer-start.browser.js 执行；不要在用户正在使用的浏览器配置文件上运行测试。测试产物写 output/playwright。

## 保留边界

- AI 拆层不承诺逐像素还原，PSD 不把图片文字自动变成可编辑字体。
- 仅编辑当前项目中的文档与独立合成输出，不覆盖原始参考图或拆层 PNG。
- 浏览器/服务暂时关闭时复用任务状态；若服务本身在付费请求途中退出，遵循现有队列失败恢复机制，不自动重发已可能收费的请求。
- JSON 不内嵌所有本地文件。备份必须保留引用素材；删除整个 output 会破坏已有项目。
