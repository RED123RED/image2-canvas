# 万物维 · Image2 节点画布

面向长期视觉创作的本地 Image2 节点工作台。提示词、参考图、Image2 模型和生成结果以模块形式存在于无限画布上，通过可视连线组成工作流。

## 启动

需要 Node.js 20 或更高版本。

```powershell
cd E:\codex\image2-canvas
$env:OPENAI_API_KEY="你的 API Key"
npm start
```

打开 `http://127.0.0.1:45173`。

服务也会尝试读取 `C:\Users\Administrator\.codex\auth.json` 中的 `OPENAI_API_KEY`。页面设置中输入的临时密钥只存在于当前页面内存中，刷新即清除。

## 节点工作流

- 提示词模块：编写和复用画面描述，输出紫色 `Prompt` 端口；编辑区支持选择文字后调整颜色和 `12` 至 `32` 像素字号，样式随项目保存，发送给生图模型时仍使用同一份纯文本内容。
- 图像模块：导入 PNG、JPG 或 WebP，输出绿色 `Image` 端口。
- Image2 模块：接收一条提示词和最多 8 张参考图，可选择 GPT Image 2、GPT Image 2.5、GPT Image 2.5 Flare 或 GPT Image 2.5 Sunburst。2.5 模型沿用 Image2 的五档比例，并额外提供 `1K`、`2K`、`4K` 输出分辨率；`2K` 为默认档位，`4K` 使用各比例允许的最大尺寸（`9:16` 为 `2160 × 3840`）。Flare 与 Sunburst 支持 `auto` 至 `max` 品质，基础 GPT Image 2.5 仅提供已确认兼容的低、中、高品质。Image2 请求会明确要求 PNG 输出，以避免网关将细节图转换为有损 JPEG。
- 模型回答模块：接收最多 6 条提示词和最多 8 张参考图，支持 GPT-5.5/GPT-5.6、DeepSeek、Claude Sonnet 4.6、Claude Opus 5.5、Kimi K3，以及通用问答、MiniMax H3 提示词、南鸢图片反推、极简产品广告和品牌宣传短片提示词输出；Kimi K3 在节点中分为“魔芋 AI”和“Moonshot 官方”两个独立选项，各自使用独立 API Key，实际请求均提交对应网关的 `kimi-k3` 模型。MiniMax H3 和品牌宣传短片模式分别提供 `自动识别`、`T2VA`、`I2VA`、`L2VA`、`FL2VA`、`Ref2VA` 模式和 `3` 至 `30` 秒逐秒时长选择；极简产品广告模式保持 `3` 至 `15` 秒逐秒时长选择。它们直接输出对应的英文 H3 视频提示词，不会直接生成媒体。自动识别按参考图数量选择结构；手动选择会覆盖它，单张图选择 `Ref2VA` 时仍只使用该图，但按多参考结构输出。
- 结果模块：生成完成后自动出现在模型右侧，并保留模型到结果的连接。
- 连线：从输出端口拖到同类型输入端口；一个输入端口只保留一条连接，重新连接会替换旧来源。
- 串联：Image2 的结果可以作为下一个 Image2 模块的参考图继续连接。

没有图片输入时调用 `POST /v1/images/generations`；存在一张或多张图片输入时自动调用 `POST /v1/images/edits`。

## 项目管理

- 首页集中显示全部项目、节点数量、连接数量和更新时间。
- 支持新建、搜索、复制和删除多个项目。
- 原单项目版本的数据会自动迁移为首页中的独立项目。
- 每个项目独立保存节点、连线、图片、视图位置和主题偏好。
- 项目数据保存在浏览器 IndexedDB；重要项目建议定期导出 `.image2.json`。

## 界面主题

- 暗黑科技：深色画布、青绿色图像流、紫色提示词流。
- 明亮清晰：高可读性白色面板和安静的浅色画布。
- 简约高级：中性灰背景、深莓红主操作和克制层级。

首页主题用于项目管理界面，新建项目时可单独选择主题；项目内部切换主题后会随项目保存。

## 环境变量

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `OPENAI_API_KEY` | 空 | Image2 API Key |
| `IMAGE2_BASE_URL` | `https://rehdasu.cn/v1` | OpenAI 兼容接口地址 |
| `IMAGE2_MODEL` | `gpt-image-2.5-sunburst` | 本机服务默认模型；节点仍可单独选择其他已接入模型 |
| `KIMI_BASE_URL` | `https://api.moonshot.cn/v1` | 覆盖 Kimi K3 的 Moonshot 官方地址；魔芋 AI 固定使用 `https://www.moyu.cn/v1` |
| `PORT` | `45173` | 本机端口 |

## 数据与费用

生成图片会显著增加浏览器 IndexedDB 和导出项目文件的体积。实际运行 Image2 会产生相应 API 费用；应用不会在打开项目、连线或浏览历史时自动发起生成。


## 轻桌面版

桌面快捷方式：`Image2 画布桌面版.lnk`

它直接调用 Node 启动 `image2-desktop-launcher.mjs`，自动检查并启动本机服务，然后用 Edge/Chrome 的应用窗口模式打开画布。前端文件仍保留在 `public/`，修改 `app.js`、`styles.css`、`index.html` 后刷新或重新打开即可生效，不需要重新打包。

## 稳定性与任务恢复

- 点击“运行 Image2”后，画布会先创建本机后台任务；浏览器页面不再直接等待网关的长响应。
- 关闭或刷新画布窗口不会中断已经进入本机任务队列的生成。重新打开同一项目后，画布会自动查询任务并回填完成图片。
- 生成结果保存为本机文件；新上传的参考图会保存到 output/assets，同时生成轻量预览图。项目仅保存本地地址，可降低浏览器 IndexedDB 因大量 Base64 图片而卡顿或延迟绘制的概率。
- 任务状态保存在 `output/image2-generation-jobs.json`，诊断日志保存在 `output/image2-generation.log`。日志仅记录任务编号、阶段、错误类别和耗时，不保存 API Key、提示词或参考图内容。
- 如果电脑或本机服务在网关生成过程中被重启，无法安全地自动重复请求（避免重复扣费）。该任务会显示为失败，可在节点中手动重新运行。
- 每次打开画布会额外进行一次不计费的模型可用性检查；顶部显示“Image2 已验证”表示本机服务、当前 Key 和默认 Image2 模型均可访问。


## 校验

修改后可执行 npm run verify 检查前端、服务端和桌面启动脚本语法；人工操作检查见 docs/REGRESSION-CHECKLIST.md。

更新 Image2 服务端代码后，需要通过首页“恢复生图服务”或重新启动桌面版加载新版本。Image 2.5 会在生成前检查比例协议版本；服务未重启时会阻止生成，避免旧服务回退为方形尺寸。
